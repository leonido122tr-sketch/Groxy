# Политика конфиденциальности и магазины

## Разрешения (Android)

В `android/app/src/main/AndroidManifest.xml` объявлено:

- **INTERNET** — доступ в сеть (логин, форум, загрузка фото в Supabase).

Выбор изображений для форума реализован через системный выбор (Photo Picker / SAF), без объявления разрешений на хранилище/медиа. Доступа «ко всем файлам» (All files access) нет. Push-уведомления на Android 13+ могут требовать разрешение POST_NOTIFICATIONS (добавляется плагином Capacitor при сборке).

## Политика конфиденциальности

В приложении есть страница **«Политика конфиденциальности»** по маршруту **`/privacy`** (`app/privacy/page.tsx`). Текст описывает: какие данные обрабатываются (аккаунт, форум, загружаемые фото), цели, использование Supabase, права пользователя и контакты.

**Для магазинов:** укажите в карточке приложения в **Google Play** и **RuStore** полный URL этой страницы, например:
- `https://ваш-домен.ru/privacy`
- или URL того места, где развёрнуто веб-версия приложения, + `/privacy`

Страница доступна без авторизации и включается в статический экспорт (`output: 'export'`), поэтому после сборки и публикации сайта ссылка будет работать. При необходимости отредактируйте текст в `app/privacy/page.tsx` (контакты, название приложения).
