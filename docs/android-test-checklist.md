# Чек-лист проверки приложения на Android

Проверять на реальном устройстве или эмуляторе после сборки: `npm run android:build` и установки APK.

## Авторизация

- [ ] **Вход по email/паролю** — ввод логина и пароля, переход в приложение, сессия сохраняется после перезапуска.
- [ ] **Вход через OAuth (Google и др.)** — нажатие «Войти через…», открытие браузера, после входа возврат в приложение по deep link (`com.groxy.app://auth/callback`), сессия подхватывается, редирект в dashboard.
- [ ] **Холодный старт по deep link** — закрыть приложение, открыть ссылку вида `com.groxy.app://auth/callback?code=...` (например из письма или тестовой страницы), приложение открывается и выполняет обмен кода на сессию, переход в dashboard.
- [ ] **Выход** — выход из аккаунта, при следующем открытии запрос логина.

## Форум

- [ ] **Список разделов** — открытие /forum, отображение категорий.
- [ ] **Список тем** — открытие раздела, список тем с превью картинки, счётчик комментариев и просмотров.
- [ ] **Просмотр темы** — заголовок, аватар и имя автора, текст и картинки, под текстом дата/просмотры/комментарии.
- [ ] **Комментарии** — ввод текста, эмодзи, прикрепление фото (булавка до ввода текста), отправка; новый комментарий появляется в списке, отображается аватар (если загружен в профиле).
- [ ] **Новая тема** — заголовок, полоска ввода (эмодзи, текст, булавка, отправка), создание темы и переход к ней.

## Профиль и аватар

- [ ] **Настройки профиля** — открытие страницы настройки профиля, изменение имени/email/города, сохранение без ошибок.
- [ ] **Загрузка аватара** — выбор фото, сохранение; аватар отображается в настройках и в комментариях форума.

## Проекты (стены, PDF)

- [ ] **Список проектов** — отображение веб- и Android-проектов, открытие проекта.
- [ ] **Создание/редактирование проекта** — шаги (параметры, фундамент, стены, крыша), сохранение, флаг «есть изменения», кнопка сохранения.
- [ ] **Сохранение на устройство (Android)** — экспорт/сохранение PDF в файловую систему, открытие файла через системный просмотрщик.
- [ ] **Шаринг** — кнопка «Поделиться», выбор приложения для отправки.

## Прочее

- [ ] **Сеть** — при отсутствии интернета показывается сообщение об ошибке, после появления сети запросы работают.
- [ ] **Статус-бар** — цвет/стиль статус-бара (если используется плагин).
- [ ] **Возврат назад** — системная кнопка «Назад» возвращает на предыдущий экран без выхода из приложения.

## Уже учтено в коде

- На нативной платформе сжатие изображений (форум, аватар) выполняется **без Web Worker**, чтобы избежать сбоев в WebView.
- Сессия Supabase на нативе хранится в **Capacitor Preferences**, а не в cookies.
- OAuth callback и создание/обновление профиля передают поле **id** в таблицу `profiles` для соответствия NOT NULL.
