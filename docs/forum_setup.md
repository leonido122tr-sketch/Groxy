# Настройка форума

## 1. Таблицы и RLS в Supabase

В **Supabase → SQL Editor** выполните скрипт из файла `forum_schema.sql` в этой папке.

Он создаёт:

- `forum_categories` — разделы (Пристрой 2/3/4 стены, Фундамент, Стены, Крыша, Другое)
- `forum_topics` — темы (заголовок, текст, автор, просмотры, ответы)
- `forum_posts` — ответы в темах
- `forum_topic_images`, `forum_post_images` — привязка фото (для будущего)
- RLS-политики и триггер обновления счётчика ответов
- Функцию `increment_forum_topic_views` для подсчёта просмотров

## 2. Фото (опционально)

Чтобы позже добавить загрузку фото в темы и ответы:

1. В **Supabase → Storage** создайте bucket `forum-images` (публичный или с RLS по необходимости).
2. В коде используйте путь вида `topics/{topicId}/{uuid}.jpg` или `posts/{postId}/{uuid}.jpg` и сохраняйте его в `forum_topic_images` / `forum_post_images`.

## 3. Навигация в приложении

- **Сообщество** (`/community`) — кнопка «Форум» ведёт на `/forum`.
- **Форум** (`/forum`) — список разделов → раздел → темы → тема с ответами, форма «Новая тема», форма ответа.
